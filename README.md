## About The Project

<p>
Picking something to watch with friends, family, or a partner is often difficult because everyone’s tastes differ. Our app solves this by having each user select titles they enjoy, learning their preferred genres, and recommending movies and series that match the whole group.
</p>


### Built With

* [Xamarin](https://dotnet.microsoft.com/apps/xamarin)
* [C#](https://docs.microsoft.com/en-us/dotnet/csharp/)
